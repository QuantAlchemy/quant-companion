Connect an agent: three directions

The MCP server is live. Users need setup steps inside the app, as ClickAlchemy has. Each direction below shows the same content: the setup prompt, the server URL, steps for each agent, what the agent can do, and how to revoke access.

  • A. A dedicated Agents page in the main navigation. Closest to ClickAlchemy.
  • B. A compact strip on the Journal page that opens setup in place. No new page.
  • C. A guided page built around the main use: paste a broker email and the journal updates.

Static mocks. Tabs and copy buttons work so you can feel the flow. Pick one, or combine parts.

Access and safety

  • The agent sees only your journal.
  • It uses your existing account names, and asks before it adds a new one.
  • Removing the server from an agent does not end its access. Revoke it in Manage account → Security.
